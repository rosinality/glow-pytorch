# 1. Data Preparation
First, download the image dataset you want to train the Glow model on and save it in a local directory. You need to have a dataset in `ImageFolder` format.

You can download the **Skin Cancer MNIST: HAM10000** dataset from the link below:

- [Skin Cancer MNIST: HAM10000 Dataset](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000/data)

The directory structure of your data set should be as follows:

    PATH/
    |
    class1/
    |   |
    |   - image1.jpg
    |   - image2.jpg
    |   - ...
    |
    class2/
    |   |
    |   - image1.jpg
    |   - image2.jpg
    |   - ...
    |
    ...
## Command Line Arguments

| Argument | Description | Default Value |
|---------|----------|------------------|
| `PATH` | Directory where images are located | - |
| `--batch` | Batch (cluster) size | 16 |
| `--iter` | Maximum number of iterations during training | 200000 |
| `--n_flow` | Number of flows in each block | 32 |
| `--n_block` | Number of blocks in the model | 4 |
| `--no_lu` | to not use LU parsing (LU parsing is used by default) | - |
| `--affine` | uses affine coupling instead of additive coupling | - |
| `--n_bits` | Number of bits of images | 5 |
| `--lr` | Learning rate | 1e-4 |
| `--img_size` | Image size (width and height) | 64 |
| `-temp` | Temperature used during sampling | 0.7 |
| `--n_sample` | Number of images to be generated during sampling | 20 |

## Dislocations during 2nd Training
During training, the sample images generated by the model will be saved in the `sample/` directory every 100 iterations. Also, the model and optimization parameters will be saved in the `checkpoint/` directory every 10,000 iterations.
## 3. Saving the Model
The model and optimization parameters will be saved in .pt format in the `checkpoint/` directory at certain intervals (10,000 iterations). These files can be used in future training phases or testing phases.
# Sample Training Command
For example, you can use the following command to train the Glow model using the HAM10000 dataset:
```bash
python train.py HAM10000
```
